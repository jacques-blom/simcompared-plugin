# Sim Compared

Find the cheapest travel eSIM

**Stop overpaying for mobile data abroad.** Tell Sim Compared where you're going, for how long and how much data you need, and it finds the lowest published price that fits, from 30+ eSIM providers checked daily. Visiting several countries? It finds one plan that covers every stop.

Already have a phone plan? See whether your carrier includes roaming where you're going, or what its roaming pass costs next to an eSIM. You can also compare pocket Wi-Fi rentals, see which network has the strongest modelled outdoor signal on a route or in a place, and check whether your phone supports eSIM.

Providers handle purchases. Sim Compared earns referral fees from some providers; this never changes prices or how offers rank.

## What you can ask

- Which eSIM gives me at least 5 GB for 10 days in Japan? Show USD prices where available.
- Which single eSIM covers Spain, France and Italy for 14 days with at least 10 GB?
- I have Verizon. Is roaming included for a week in Mexico, or should I get an eSIM?

## Set up

Add the Streamable HTTP server for your assistant. Use `https://mcp.simcompared.com/chatgpt` in ChatGPT and `https://mcp.simcompared.com` in Claude or other clients. You can use the eight read-only tools without signing in. The [setup guide](https://simcompared.com/mcp) has instructions for ChatGPT, Claude, Cursor and VS Code. For Claude Code, install the generated package locally with `claude --plugin-dir /path/to/simcompared-claude`.

Use the result’s page link for prices, evidence and terms. Providers handle purchases. Sim Compared earns referral fees from some providers. Rankings and prices are unaffected.

Install from the Claude Code marketplace with `/plugin install simcompared --marketplace jacques-blom/simcompared-plugin`.
