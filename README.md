# Sim Compared

Compare published prices for travel eSIMs, home-carrier roaming and pocket Wi-Fi. Tell your assistant where you’re going, how long you’ll be there and how much data you use. It can also check outdoor mobile coverage or whether your exact phone variant supports eSIM.

## What you can ask

- What is the cheapest eSIM with at least 5 GB for 10 days in Japan?
- Which single eSIM covers Spain, France and Italy for 14 days and at least 10 GB?
- Does my Verizon plan include roaming in Mexico?
- Which network has the best 4G coverage on the Great Ocean Road?

## Set up

Add `https://mcp.simcompared.com` as a Streamable HTTP MCP server. You can use the eight read-only tools without signing in. The [setup guide](https://simcompared.com/mcp) has instructions for ChatGPT, Claude, Cursor and VS Code. For Claude Code, install the generated package locally with `claude --plugin-dir /path/to/simcompared-claude`.

Use the result’s page link for prices, evidence and terms. Providers handle purchases. We may earn a commission when you follow a provider link. It has no effect on the price or ranking.
