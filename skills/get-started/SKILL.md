# Get started with Sim Compared

Ask where the traveller is going and roughly how long only if they haven’t said. If they named a carrier, phone or route, use that detail to choose `carrier_roaming`, `phone_esim_support`, `coverage` or `route_plans`. For a destination and trip, follow the find-an-esim skill and show one matching offer straight away.

The tools work without a Sim Compared account. Cite the human result page and use signed `go_url` values for opening providers. Keep the result’s `disclosure` line beside provider links.
