# Get started with Sim Compared

Start with the question the traveller already asked. For an eSIM in one destination, use `compare_plans` once you know the destination, days and minimum total data. Ask only for missing required details. Use `route_plans` for one eSIM across countries, `coverage` for outdoor mobile signal, `carrier_roaming` for a named carrier's roaming rates, `pocket_wifi` for a rental hotspot and `phone_esim_support` for device compatibility. If the traveller has given no task, ask what they want to compare.

The tools work without a Sim Compared account. Use the human-facing comparison or source page. Use the returned signed provider link when sharing a booking option. Show the returned disclosure the first time you share a booking link in a conversation.
