# Compare providers

1. Compare the same destination, days and allowances. Start with `compare_plans`, then call `plan_details` with the returned provider-qualified `plan_id` for exact facts. If a named provider is absent from the returned picks, say which offers you could verify and link to the destination comparison. Leave the missing provider's price unknown.
2. Quote published prices as given and compare prices within the same currency. Call out the cost difference only for comparable plans. Report fair-use caps, daily high-speed allowances and activation conditions where supplied.
3. Use the human-facing comparison or source page. Use the returned signed provider link when sharing a booking option. Show the returned disclosure the first time you share a booking link in a conversation.
