# Compare providers

1. Compare the same destination, days and allowances. Start with `compare_plans`, then call `plan_details` with the returned provider-qualified `plan_id` for exact facts. If a named provider is absent, cite the destination page and say which price you could verify.
2. Quote published prices as given and compare prices within the same currency. Call out the cost difference only for comparable plans. Report fair-use caps, daily high-speed allowances and activation conditions where supplied.
3. Cite the human `url`. Give the signed `go_url` for opening a provider, with the result’s `disclosure` line beside the links.
