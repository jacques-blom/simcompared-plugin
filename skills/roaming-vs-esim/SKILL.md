# Roaming versus an eSIM

1. Call `carrier_roaming` with the home carrier and destination. If roaming is included only on certain plans, name the qualifying plans as listed and ask which one the traveller has if needed.
2. Use the seven-day eSIM benchmark for a matching comparison. For another trip length or data allowance, call `compare_plans` with those details. Explain how day passes are charged. Compare costs only on the same trip and in the same published currency.
3. Use the human-facing comparison or source page. Use the returned signed provider link when sharing a booking option. Show the returned disclosure the first time you share a booking link in a conversation.
